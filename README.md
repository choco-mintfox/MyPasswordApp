# パスワード生成アプリ

指定した文字数や条件（数字・記号の有無）に合わせて、安全なパスワードを即座に自動生成するWebツールです。

## パスワードジェネレーター
[ここをクリックしてツールを試す](https://choco-mintfox.github.io/MyPasswordApp/)

## 主な機能とこだわり
- **柔軟な文字数設定**: 8文字、16文字、32文字のワンタップ切り替えに加え、テキストボックスから8〜32文字の間で1文字単位の自由入力を可能にしました。
- **入力連動UI**: テキストボックスに数字を入力すると、自動でラジオボタンが切り替わる直感的な操作性を意識しました。
- **レスポンシブ・セーフ**: 24pxの見やすい文字サイズを維持しつつ、最大文字数の32文字になっても枠線からはみ出さないよう、等幅フォント（Courier New）の特性を活かしたCSS設計をしています。

## 使用技術
- HTML5
- CSS3
- JavaScript
